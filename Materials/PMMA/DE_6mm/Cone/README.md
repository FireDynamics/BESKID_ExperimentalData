# Cone Calorimeter Experiments

Experiments have been conducted, with sample in horizontal orientation. Samples were wrapped in aluminium foil. No retainer frame or grid have been used.

Different types of insulation material have been used below the PMMA samples: CaSiO3 and Al2O3. The goal was to an insulation material that has a more reproducible behaviour compared to the common fiber blankets. The CaSiO3 block below the sample was manufactured from the same boards used as backing of the large scale experiments. However, it was found that these boards contain a lot of moisture making the mass loss measurements unreliable. For this reason new cone experiments were conducted using a block of Al2O3 as insulation material.
